# CAST Imaging Plugin

AI-powered analysis skills for [CAST Imaging](https://www.castsoftware.com/imaging).

## Skills

| Skill | Description |
|-------|-------------|
| `impact-analysis` | Evaluate the scope and risk of code changes across your application landscape |

## Commands

| Command | Description |
|---------|-------------|
| `/CAST-Imaging:impact-analysis [application] [object_name]` | Run impact analysis on a code object |

## Prerequisites

- [CAST Imaging MCP server](https://www.castsoftware.com/mcp) installed and configured in your Claude Code settings
