# MBE — Community Skills

Spring/Java application review skills powered by CAST Imaging.

## Skills

| Skill | Description |
|-------|-------------|
| [`api-security-review`](imaging/skills/api-security-review/) | Detect missing or decorative input validation on Spring controllers |
| [`caching-review`](imaging/skills/caching-review/) | Identify caching patterns and gaps in a Spring application |
| [`database-tables`](imaging/skills/database-tables/) | Explore database table usage via CAST Imaging database explorer |
| [`error-handling-review`](imaging/skills/error-handling-review/) | Audit error and exception handling patterns |
| [`full-review`](imaging/skills/full-review/) | Full architectural review across all layers |
| [`http-client-review`](imaging/skills/http-client-review/) | Detect and audit HTTP client usage patterns |
| [`jdbc-review`](imaging/skills/jdbc-review/) | Find raw JDBC (`java.sql.*`) usage |
| [`jdbcTemplate-review`](imaging/skills/jdbcTemplate-review/) | Audit Spring JdbcTemplate usage |
| [`layering`](imaging/skills/layering/) | Check layer boundary violations |
| [`logging-review`](imaging/skills/logging-review/) | Review logging coverage and patterns |
| [`modules-analysis`](imaging/skills/modules-analysis/) | Analyse module structure and inter-module dependencies |
| [`persistence-jpa-review`](imaging/skills/persistence-jpa-review/) | Review JPA persistence layer quality |
| [`persistence-layer`](imaging/skills/persistence-layer/) | Detect persistence layer architecture violations and N+1 patterns |
| [`resilience`](imaging/skills/resilience/) | Identify missing resilience patterns (retry, circuit-breaker, timeout) |
| [`rest-api-review`](imaging/skills/rest-api-review/) | Audit REST API design and quality |
| [`superfluous-libs-review`](imaging/skills/superfluous-libs-review/) | Detect unused or redundant library dependencies |
| [`transactional-review`](imaging/skills/transactional-review/) | Review `@Transactional` usage and transaction boundary alignment |
