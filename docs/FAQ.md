# FAQ

## What is a CAST skill?

A skill is a reusable AI-powered capability that Claude Code makes available. CAST skills help you analyze code and make better decisions.

## How do I install the marketplace?

```bash
/plugin marketplace add cast/cast-plugins
/plugin install cast-skills
```

## How do I use a skill?

Once installed, mention the skill in your conversation:

```
Use the impact-analysis skill to evaluate this change.
```

## Can I request new skills?

Yes! Open an issue on GitHub describing the skill you'd like to see.

## How often are skills updated?

Skills are updated as new capabilities are developed. Run `/plugin marketplace update` to get the latest version.

## What if I find a bug?

Please report it on GitHub with:
- Description of the issue
- Steps to reproduce
- Expected vs actual behavior

## Are there plans for more skills?

Yes! We're planning skills for:
- Code quality analysis
- Security assessment
- Architecture review
- And more

Follow the marketplace repository for announcements.
